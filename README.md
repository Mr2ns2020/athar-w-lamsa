# أثر ولمسة

المصدر الرسمي لموقع **أثر ولمسة** على `atharlmssa.com`.

## تحديث المنتجات

تُدار المنتجات من `products.js`. أضف صورة المنتج إلى المجلد المناسب، ثم أضف سجلًا جديدًا يحمل رقمًا فريدًا والاسم والتصنيف والسعر ومسار الصورة.

## الملفات الرئيسية

- `index.html`: هيكل الصفحة ومحتواها.
- `styles.css`: الهوية والتصميم المتجاوب.
- `products.js`: المنتجات والأسعار.
- `app.js`: البحث والتصفية وسلة الطلب وواتساب.
- `CNAME`: ربط الدومين، ويجب إبقاؤه دون تغيير.

## الهوية

الأسود `#0B0B0B`، العاجي `#F5F0E6`، الذهبي `#C9A227`، والخط العربي Cairo.
