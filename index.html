الخصوصية

نستخدم البيانات اللازمة للتواصل وتنفيذ الطلب فقط، ولا نطلب بيانات بطاقات الدفع عبر الموقع.

الاسترجاع والاستبدال

تتم معالجة الطلبات وفق الأنظمة المعمول بها، وقد تخضع المنتجات المخصصة لاستثناءات بحسب طبيعة التخصيص ويتم توضيحها قبل التنفيذ.

الشحن والتسليم

يتم تأكيد منطقة الشحن ومدة التجهيز والتوصيل والتكلفة قبل اعتماد الطلب.

الدفع

يتم تأكيد طريقة الدفع وتفاصيل الطلب مع العميل قبل التنفيذ.

الشكاوى والاقتراحات

يمكن إرسال الشكاوى والاقتراحات عبر واتساب أو البريد الإلكتروني.

الشروط العامة

يتم اعتماد تفاصيل التصميم والتخصيص قبل التنفيذ، وأي تعديل بعد بدء التنفيذ قد يؤثر على الوقت أو التكلفة.
