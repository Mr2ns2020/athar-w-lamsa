معلومات المتجر

السياسات والشروط

الخصوصية

نستخدم البيانات التي ترسلها لخدمة طلبك والتواصل معك بشأنه، ولا نبيع بيانات العملاء.

الاسترجاع والاستبدال

تتم معالجة المنتجات الجاهزة حسب حالة المنتج. المنتجات المخصصة قد تختلف أحكامها، لذا تواصل معنا قبل التنفيذ.

الشحن والتسليم

يتم تنسيق بيانات الشحن وموعد التسليم قبل إتمام الطلب، وتختلف المدة حسب المدينة وطبيعة الطلب.

الدفع

يتم تأكيد طريقة الدفع والمبلغ مع العميل قبل تنفيذ الطلب. سيتم إضافة بوابة الدفع الآمن بعد اعتماد مزود الدفع.

الشروط العامة

يجب مراجعة تفاصيل المنتج والتصميم والكمية واعتماد التصميم قبل بدء تنفيذ المنتجات المخصصة.

الشكاوى والاقتراحات

يمكنك إرسال شكوى أو اقتراح من النموذج، وسنتواصل معك لمتابعة الملاحظة.

أسئلة شائعة

الأسئلة الشائعة

كيف أطلب تيشيرت؟

اختر المنتج، ثم حدد المقاس واللون والكمية، وبعدها أضفه للسلة.

هل يمكن تعديل الكمية بعد الإضافة؟

نعم، افتح السلة وعدل الكمية أو احذف أي منتج قبل إرسال الطلب.

كيف يتم إرسال الطلب؟

بعد مراجعة السلة اضغط «إرسال الطلب عبر واتساب» وستُجهز رسالة كاملة بتفاصيل المنتجات.
