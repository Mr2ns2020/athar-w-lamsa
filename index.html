وضوح وثقة

سياسات المتجر

السياسات التالية توضح الإطار العام للطلبات، ويتم تأكيد التفاصيل الخاصة بكل طلب قبل التنفيذ.

سياسة الاسترجاع والاستبدال

يمكن طلب الاسترجاع أو الاستبدال وفق الأنظمة المعمول بها وشروط المنتج. المنتجات المخصصة أو المصنوعة حسب طلب العميل قد تكون لها استثناءات بحسب طبيعة المنتج، ويتم توضيح ذلك قبل التنفيذ.

الشحن والتسليم

يتم تأكيد منطقة الشحن ومدة التجهيز وتكلفة التوصيل قبل اعتماد الطلب. قد تختلف المدة حسب المنتج والتخصيص والكمية.

الخصوصية وحماية البيانات

نستخدم بيانات العميل اللازمة للتواصل وتنفيذ الطلب فقط، ولا نطلب عبر الموقع بيانات بطاقات الدفع أو كلمات المرور. لا نشارك بيانات العملاء إلا عند الحاجة لتنفيذ الخدمة أو إذا تطلب النظام ذلك.

الدفع

طريقة الدفع وتفاصيلها يتم الاتفاق عليها وتأكيدها قبل تنفيذ الطلب. لا يتم اعتبار الطلب نهائيًا حتى يتم تأكيد تفاصيله مع العميل.

الشكاوى والاقتراحات

يسعدنا استقبال الملاحظات والشكاوى عبر واتساب أو البريد الإلكتروني، ونعمل على معالجة المشكلة والتواصل مع العميل بأسرع ما يمكن.

الشروط العامة

إرسال الطلب يعني موافقة العميل على تفاصيل المنتج والتخصيص التي تم اعتمادها قبل التنفيذ. أي تعديل بعد بدء التنفيذ قد يترتب عليه وقت أو تكلفة إضافية حسب الحالة.
